Your test function:

JavaScript
testBill()

runs directly from Apps Script, so it runs under your authorized account.

Your eventual website request will run according to the web-app deployment setting. If you deploy it as "Execute as me", Drive/Sheet operations run under the deploying account. If you deploy it as the accessing user, permissions behave differently. Google for Developers
