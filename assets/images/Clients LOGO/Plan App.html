Encrypted XML design

Don't simply Base64-encode the XML. Base64 is not encryption.

The recommended structure is:

Original Job Data
       ↓
XML serialization
       ↓
Compress (optional)
       ↓
AES-256-GCM encryption
       ↓
Encrypted XML container
       ↓
.xml file

For password-based encryption, derive the encryption key using a modern password KDF such as PBKDF2-HMAC-SHA256 with a randomly generated salt.

The file could look conceptually like:

XML
<?xml version="1.0" encoding="UTF-8"?>

<PrintingCalculatorBackup
    version="1"
    encrypted="true"
    algorithm="AES-256-GCM"
    kdf="PBKDF2-SHA256">

    <metadata>
        <created>2026-08-16T10:30:00Z</created>
        <appVersion>1.0.0</appVersion>
    </metadata>

    <encryption>
        <salt>...</salt>
        <iv>...</iv>
        <iterations>600000</iterations>
    </encryption>

    <data>
        ...
    </data>

</PrintingCalculatorBackup>

The actual job data should be encrypted; don't leave sensitive job information readable in the XML.

46. Offline-first behavior

This is especially important for a printing application.

The user should be able to do these things without internet:

  • Login using an already-authorized local session

  • Create job

  • Calculate

  • Save job

  • Edit job

  • Delete job

  • Search jobs

  • Export encrypted XML

  • Import encrypted XML

  • Print

  • Generate quotation

Internet is only needed for things such as:

  • Checking updates

  • Remote admin configuration

  • Future cloud synchronization

So the calculator remains useful even inside a printing shop with poor/no internet.

48. Important security architecture

Your current website has:

JavaScript
const ALLOWED_USERS = [
    { username: "admin", password: "ChangeThisPassword123" }
];

Do not copy that approach into the Android production app.

An APK can be inspected.

Instead:

Admin account
      ↓
Secure authentication
      ↓
Password hash
      ↓
Authenticated session
      ↓
Role
      ↓
Permissions

And for encrypted backup:

Job Database
     ↓
XML serialization
     ↓
AES-256-GCM
     ↓
Encrypted XML
     ↓
User-selected location

The encryption password should not be embedded in the application.
